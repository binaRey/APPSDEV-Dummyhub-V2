# DummyHub

Single-page app (vanilla JS, ES modules) consuming the DummyJSON API.

## Run
Open the `dummyhub/` folder in VS Code and start **Live Server** (modules do not load from `file://`).

## Status
Phase 1-3b complete: shell, auth, Shop, Cart, Recipes, Community, People, Tasks, Dashboard. Tip: open the app with ?delay=1500 to slow every GET and demo the loading state.
